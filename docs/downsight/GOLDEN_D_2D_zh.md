# 当前黄金 D：全二维身体观测损失

用户已决定以 `golden-d-2d-v1` 作为后续研究的默认黄金 D。当前配置清单为 [golden_d.current.json](../../configs/golden_d.current.json)，固定参考实现为 [newdetector_d10/fit.py](../../runs/2026-11-17_newdetector_d10/fit.py)，参数沿用其 [protocol.json](../../runs/2026-11-17_newdetector_d10/protocol.json)。清单用于识别研究基线，不是原 EgoSMPLX CLI 的配置文件。

## 方法定义

从 SMPL-X 均值体型和模板姿态出发，根据 Head 位置与朝向初始化根位姿。左右相机约束同一套人体参数，模型关节通过各自标定投影后，与身体二维检测点形成重投影残差。

身体观测损失为 `L_body_2d`；总目标还包括 Head 位置、Head 朝向、姿态先验、体型先验及正深度惩罚，并限制旋转范围。三角化身体三维残差的贡献为零，不与二维残差混合。全二维并不表示输出是二维，也不表示移除 Head 三维锚点。

参考实现按协议像素尺度归一化二维距离，再使用 Huber 损失；先在关节的有效视角间归约，再按身体、肩、腕组归约并加权。相机、Head 来源、有效点策略、权重和归约规则都属于实验条件，不能仅凭 `methods=["2d"]` 就认定任意运行与参考等价。

## 当前固定参考

- `methods=["2d"]`，`conditions=["baseline"]`，不做参考标签替换。
- 检测器为 Sapiens2-1B 全骨干微调第 1 轮；参考数据与模型来源沿用原 run 的证据。
- 预算、学习率计划和检查点选择沿用固定协议；只按训练目标选择可行输出，身体三维 GT 只在拟合结束后用于评价。
- 当前参考体型基底秩为零，实际固定均值体型；未加入 WiLoR 手部观测，手指局部姿态固定。全二维方法本身不意味着体型永远不可优化，后续扩展需单独记录并对照。
- 参考使用标注 Head 位置、历史估计 Head 朝向、标注派生外参和固定画内掩码，保留低置信度二维预测。这些条件不能视作线上可直接取得。

源码仍保留历史三维数据结构及体型基底计算接口，但参考配置关闭三维观测路由，实际体型基底为零。现有源码的默认本地路径指向历史实验输出；复跑须使用新 run 和独立输出目录，显式准备输入、记录路径和哈希，不能直接用旧默认路径覆盖输出。当前清单固定来源与身份，不是通用部署启动器。
