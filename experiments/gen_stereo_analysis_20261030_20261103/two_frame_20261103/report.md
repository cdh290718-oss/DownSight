# Gen 双目三角化与 DFM / 实验 C 对照

## 数据范围和结论
使用同一视频的 `gen_00000`、`gen_00270` 两个既定时刻，每个时刻各两张双目图。预先选择 00270 为源清单中 00000 后的下一时刻；只为其两张图运行既有 Sapiens2-1B。原结果、标定与流程代码均未改动。搜索到的其他 Sapiens 缓存均是 00000 的重复：两侧各 7 份，同侧关节坐标和分数完全一致。另有 18 个时刻仅找到图像和 DFM，没有已有 Sapiens 结果，本次未批量推理。

实验 C 只有 00000/cam3 的身体姿态拟合；00270 没有该时刻的 C 结果。两时刻的肩肘腕骨长可以与 00000 的 C 身体骨长作条件性参考，但肩宽随锁骨姿态变化，头到手的距离随动作变化，不能当作第二时刻的 C 实测值。

最明显的反例在 00270：左右肘在 cam3 相距 10.4 px、cam4 相距 12.9 px，三角化位置相距 0.9 cm；左右腕分别相距 2.9 / 3.3 px，三维相距 1.8 cm。它们高度疑似将同一条可见手臂当成左右两臂。右肘与右腕的对极残差为 5.7 / 1.8 px，右前臂三角长度 23.8 cm 与 C 的 24.0 cm 也接近。**因此，对极通过、深度合理、单根骨长合理均不能保证身份或位置正确。**

对 00000，双腕三维坐标与 DFM 相距 1.2 / 1.1 cm；双肘相距 8.4 / 10.0 cm。两肘各视角自动点均落在衣物投影上；左右图中 Sapiens 与 DFM 肘投影相隔 21.3 / 26.6 px（左）及 47.8 / 43.9 px（右）。两种位置的肘部 21×21 邻域均被 Sapiens 分割为 Upper_Clothing，不能区分袖子表面与被衣物遮挡的真实关节，也无法判定是 Sapiens 深度偏近、DFM 肘不准，还是两者都有偏差。

00000 的左髋、右髋、左膝和左踝三角距离为 35.0、45.9、52.8、44.8 cm，与 DFM 的三维差为 34.6、26.4、51.9、98.5 cm；对应点在图中落在上衣或袖子投影附近，且分割也预测为 Upper_Clothing。这支持“疑似不可见而不宜直接信任”，但仅有二维图像与射线解，不能证明三维位置确实落在托盘或衣物表面。

DFM 文件自己的说明只建议参考手和腕；本报告把身体其它关节作为对照，不当成真值。不同来源的人体关节点定义也可能存在差异。00270 的 DFM 右肘与右腕投影在画面外，且 DFM 身体点没有独立标注验证。

[00000 的分割叠加](elbow_segmentation_00000.png)：橙色为 Upper_Clothing，绿色为手臂类别；青点、白菱形、紫叉分别为 Sapiens、DFM、C。第一帧四个视角/肘位置上，Sapiens 点和 DFM 投影点的 21×21 像素邻域均为 Upper_Clothing。分割来自另一个自动模型，不能作为关节中心或深度真值。

00000 左肘三角/DFM 距离 38.3/46.5 cm；右肘 38.7/48.0 cm。三角范围对两图每坐标独立 σ=3 px 的线性化随机敏感度分别约 2.17/2.26 cm，不能解释成已测量的真实误差，也未包含标定、同步、检测系统偏差或 DFM 不确定性。两侧可见衣袖说明有图像证据，但关节中心被衣物覆盖；左肘两种投影都在袖附近，右肘 DFM 投影靠近躯干衣物边缘。现有证据不能确定哪一个三维肘点更准确。

## 方法和局限
用源文件 `sourceParams` 的 Double Sphere 模型反投影到单位射线，用 cam3 射线上的两射线最近解三角化；正深度之外不给有效距离。相对 R/t 是上一轮由 DFM 两路身体坐标刚体配准得到的 5.566 cm 基线，20帧内部残差近机器精度。这说明坐标数据互相一致，**不能独立证明相机标定或 DFM 关节准确**。

DFM NPZ 仅含 22 点数组，未保存名称；报告按 SMPL 常见22点顺序映射肩肘腕/髋膝踝和头，与上一轮腕肘对照一致，但要向数据生成源核实关节定义。Sapiens、DFM、SMPL-X 对关节中心的定义和衣物遮挡可能不完全一致。

距离敏感度是像素独立零均值高斯 σ=3 px 的条件性线性化，不包括点身份混淆、系统误差、遮挡、同步与标定误差；因此不能把“落在几倍 σ 内”用作准确率保证。

可以将对极残差、图像内可见性、跨侧重复、射线夹角、骨长范围、二维图像证据和参考差异一起作为**可疑点提示**；这些样本尚不足以设定通用阈值或证明可可靠分类。进一步区分肘点成因需要独立标注/其他视角/可靠深度或经验证的三维真值。
