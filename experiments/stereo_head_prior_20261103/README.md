# 双目头部先验：多帧原型与四组对照

[实验报告](report_v2.md) · [全部指标](metrics_v3.json) · [完整模型示例](overlays/frame_02700_stereo.jpg) · [去掉头部可见性约束](overlays_no_visibility/frame_02700_stereo.jpg)

该实验在 20 个稀疏时刻上研究双目三角化、头部可见性和共享头相机变换；前 10 帧用于估计共享变换，后 10 帧固定变换并评估。报告显示双目三角化和头部可见性各有作用，但共享变换稳定并不代表安装位姿准确，拟合头关节与 DFM 参考仍存在偏差。DFM 身体关节和代理朝向并非全部经过独立验证的真值。

目录含报告、指标、标定、四个时刻两组叠加图，以及当时的优化和评估脚本。脚本是历史探索代码，仍依赖开发机绝对路径、原始输入、自动观测、DFM 参考数据、模型和环境；**不是独立可运行的完整复现包**，也未作为开关模块合入 DownSight 主流程或在本次重新运行。原始材料位于开发机 `EgoFishPose/experiments/stereo_head_prior_20261103/`。`report_v2.md` 只调整了末尾资产说明，以避免把未上传的观测标成仓库内可用文件；实验结论及指标未修改。
