# 不足、结论边界与后续验收

[返回实验入口](README.md)。以下不足属于结果解释的一部分，不应在引用该基线时省略。

## 可以据此主张什么

在这一个合成姿态、准确生成标定、真值 Head 位姿输入的条件下，预先指定的 `oracle_left` 在本次报告列出的对照中取得较低的身体平均误差。同初始化 legacy 对照表明整套改动改善了身体、体型、腕和手指误差；可作为后续身体拟合方法的候选基线。主结果和完整对照见 [RESULTS.md](RESULTS.md)，没有声称独立重新复现。

## 不能扩大为哪些结论

| 边界 | 已观察到的事实 / 实现限制 | 对结论的影响 |
|---|---|---|
| 人体真值依赖 | oracle 输入真实 Head 位置和朝向；整体人体评测包含被头部输入间接约束的部位 | 不是从图像独立恢复人体全部几何；头部误差接近零主要反映服从输入锚点，不是头部估计精度 |
| 准确相机依赖 | 使用生成时的内外参、畸变与米制基线 | 未测试真实标定漂移、畸变模型失配、相机不同步；不能直接部署结论 |
| 样本覆盖 | 一个人体姿态的两目，非两个独立姿态；无跨人、跨姿态统计 | 不能提供泛化均值、统计显著性或成功率；两目三维误差一致是坐标一致性，不是独立重复实验 |
| 均值真值优势 | 合成真值 beta 全为零；本方法将九个弱方向固定为零 | 中性体型误差变小可能主要受益于正确的均值假设，不能证明恢复了非均值身形、粗细或体表形状 |
| 局部信息近似 | 独立骨长近似忽略端点相关性及姿态耦合，肩宽也受锁骨旋转影响 | “只保留一维”不保证是真实可观测子空间；阈值与噪声未单独做敏感性消融 |
| 定义差异和偏差 | 肩、髋用米制噪声放软，但目标仍对应内部关节；检测偏差不一定零均值 | 白化与鲁棒损失不能自动消除系统偏差，深度协方差也不含相机误差 |
| 证据相关性 | Sapiens/WiLoR 腕被分别使用，骨长共享端点，多点检测误差可能相关 | 目标和信息矩阵不是完整联合概率模型，不能把数值权重当已校准置信度 |
| 单因素归因 | 新目标、手点集合、体型子空间一起改变；新初始化与原 B/E 也不同 | 只能主张整套新方法优于同初始化旧目标，不能给各项改动分配独立收益 |
| 手部范围 | 固定 SMPL-X 手指参数，未接回原 MANO 替换/接缝；手部目标只含腕和掌指点 | 不是原完整手部输出的直接替代；腕误差小不保证各指尖姿态、表面接缝正确 |
| 物理与可见性 | 无轮廓项、碰撞项或头部顶点入画惩罚；只保护观测关节正深度 | 允许未观测网格在相机后方，不保证不穿设备、不自交或轮廓正确；参数限幅也不是完整解剖约束 |

## 本组仍然存在的具体误差

- 骨盆误差 **42.14 mm**，cam3 的预测减真值 XYZ 约为 **(+4.15, −41.83, +2.99) mm**。剩余误差主要在 Y 方向，不能继续概括成纯粹“人体被推远”；这也不是已识别的唯一原因。
- 双肘 **22.68 mm**，仍高于旧 D 的 **19.68 mm**；身体均值更低不代表每个部位都更好。
- 主结果触及增量上限的关节为 `R_Collar, L_Elbow, R_Elbow, L_Wrist, R_Wrist`。这是相对网络初值的优化增量上限，不是已达到真实解剖极限；不能宣称已无约束瓶颈或达到全局最优。
- 改用右目网络初值，身体误差为 **39.71 mm**，中性体型误差从主初值的 **5.68** 变为 **13.48 mm**。因此初始化敏感性和体型/姿态耦合仍然存在。

上述数字和触限列表来自 [evidence/results.json](evidence/results.json)；源 run 保留每步摘要、参数重建检查与实际输出哈希。

## 无锚点与扰动组说明了什么

无头部锚点主组不使用人体真值参与初始化或目标，身体误差 **44.85 mm**，但头部位置/朝向误差仍为 **38.12 mm / 14.92°**；它依然使用已知生成相机。它比 oracle 更接近实际使用条件，但不能因此称为已经验证的部署配置。

扰动组是在真实 Head 上加平移范数 10/20 mm、旋转角 3°：两个预定方向取正负，共八次压力测试。它们不是逐坐标独立的 ±2 cm 随机采样，也不是统计置信区间，更没有覆盖所有误差方向。模型的头部基本继承输入扰动，不能说双目已自动修正错误锚点。把真值关节替换成实测安装位置，还需要定义设备坐标系到模型 Head 坐标系的变换，以及佩戴变化和个体头部定义差异。

## 后续验证的验收方向（尚未执行）

1. **非均值体型、多姿态**：同一个体跨姿态共享 beta，在未参与拟合的姿态评价；覆盖不同身形，检验均值先验是否抹掉真实差异。
2. **模块消融**：在相同初始化和头部条件下分别改变三维目标、手点集合、体型子空间，区分独立贡献与交互，不根据测试真值选权重。
3. **真实安装与标定误差**：使用独立实测头—相机变换，校验内外参；评测扰动敏感性和姿态误差，而非只评价锚点服从程度。
4. **剩余身体误差**：检查髋/肩检测定义、关节触限、躯干和腿的观测覆盖；保留独立手部指标，防止改善躯干时牺牲手腕。
5. **完整输出**：接回 MANO 与接缝后重新评测手指、网格连续性和轮廓；该验收通过之前不把本组作为黄金样本完整流程的替代版本。
