# Sapiens2 接入清单

1. **获取并核验数据源。** 找到 UnrealEgo2 原始 RGB、姿态 JSON、官方划分及标定；当前本机搜索范围见报告。RW 的原始 pose/RGB 根路径不可访问，缓存只有压缩分卷，现有 100 图为验证集检查样本，不得用于训练。确认数据许可与公开范围后准备独立训练子集，按官方序列划分并检查人物、序列及双目对不交叉。
2. **转换为 308 点。** 用 [audit.json](evidence/audit.json) 中的准确索引逐名映射；特别是右腕 41、左腕 62。保留原始字段与原始图片尺寸，鼻点缺失时置零权重，Head 不替代鼻点。现有转换生成候选坐标，所有训练权重为零，尚不可训练。逐点确认坐标、左右、姿态骨骼与 Sapiens 表面标记语义以及遮挡，不把自动写入的第三列 1 当作可见性。
3. **数据加载器和裁剪。** 在 DownSight 仓库内建立适配代码，复用官方 `PoseBaseDataset` 契约，保留样本 ID、图片路径、原尺寸、裁剪、双目配对、split、来源标定和有效性；校验路径、图片哈希及标签尺寸。当前推理使用全图 bbox，经官方 test pipeline；训练裁剪、尺寸、颜色和归一化应与其一致，先关闭强裁剪及遮挡增强，左右翻转时同步交换关节。
4. **缺失标签屏蔽。** 输出 308 点数组及逐点权重，未监督通道和缺失点的目标权重设为 0；沿 `PoseGenerateTarget` → UDPHeatmap 的 `keypoint_weights` → `KeypointMSELoss(use_target_weight=True)` 核查端到端屏蔽。官方 loss 对所有位置和通道求 mean，稀疏监督会改变有效损失尺度；需实测有效点归一化及零掩码梯度，记录同条件对照。仅验证后解除有效点掩码。
5. **配置与权重。** 采用本机 1B pose checkpoint 完整加载、维持 308 输出；先冻结主干大部分参数并明确可训练层，按用户要求用 BF16。独立输出配置、初始权重 SHA-256、训练数据清单、保存策略、依赖版本和日志。当前设备支持 BF16，但尚未跑训练或验证显存，实际 batch 和吞吐未知。
6. **评估与下游。** 提前固定独立验证集；记录每关节误差、有效/缺失和遮挡口径、固定阈值正确点数、推理时间。将 308 点结果转换成现有 Sapiens JSON 后，用原样三角化和 D 代码及同一验证双目对分别评估；报告失败、可用点、3D 和 PA-MPJPE，不能用验证/测试调参。先跑基线和小样本拟合、200–500 步资源短测，通过后再正式训练。
