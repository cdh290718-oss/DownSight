# 单帧双目图块能否选对腕部深度？

在原有 100 对冻结 RW20000 样本上，黄金 D v2 的双腕三维 RMSE 为 108.91 mm。同一批肩肘姿态候选中，用真值事后选择离真实腕最近的解可到 43.75 mm，实际图像选择为 94.15 mm。按独立验证人物的事先准入条件，图像方案未通过，实际回退黄金 D v2。

## 候选、图像特征与评分

从每帧原始黄金 D 姿态出发，保留原腕，再分别沿拟合腕射线和左眼检测射线取近远候选。用两连杆逆运动学还原肩、肘局部旋转，选尽量接近当前肘部弯曲平面的解；越出臂长、肩肘角度或正深度范围的候选排除。根位姿、体型和其他局部关节固定。两臂独立选，再合为一套真正的 SMPL-X 参数。原损失使用 v2 完整目标评估。

每个腕候选投到两个原始鱼眼图。在腕周围与朝肘部的前臂上取两个有方向的图块，按投影的前臂方向对齐，对去均值的三通道像素求归一化互相关。图像分数结合原目标的增量，屏蔽纹理不足、越界或缺必要观测的候选，证据差距过小则保留原解。原型使用手工图像描述子，无新训练网络、时序输入或测试真值。选解和评分分进程；仅事后 oracle 读真值来选腕。完整人体参数与候选库保存在开发机。
