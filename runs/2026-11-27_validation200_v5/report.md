## 实现与复核

基线 35b6949，工作树有本轮新增脚本和既有无关改动。v3、v4 取链接报告冻结结果，v4 对应 fixed_full。逐帧核验 v4 参数哈希。重新把 400 张原图按各眼标定转成 640×480、水平视场 125° 的透视图，按冻结入口运行 WiLoR。用同帧 RW20000 的 308 点预测中对应的手部通道作双目观测，按原始 872 像素图像边界判断有效性，再变换到标定像素系。逐手复用冻结程序 choose_hand 的候选转换、腕旋转拟合和选解规则，缺失候选或有效观测时保留 v4。封存 200 份结果后才读取官方三维参考作评分。

开发机依赖既有受限模型、检测、原图及 v4 参数。执行命令从仓库根目录运行。

```sh
r=runs/2026-11-27_validation200_v5
python -B "$r/launch.py" predict_new
python -B "$r/launch.py" measure fit
python -B "$r/launch.py" measure score
```
